# Podcast Jelajah Malam Dashboard

Dashboard frontend siap pakai. Tidak membutuhkan database atau instalasi.

Cara membuka:
1. Extract ZIP.
2. Buka file `index.html` dengan Chrome/Edge.
3. Data tersimpan otomatis di browser perangkat tersebut.

Fitur:
- Dashboard statistik
- Stok video / narasumber
- Tambah & edit data
- Status Belum Diedit / Editing / Siap Tayang / Sudah Tayang
- Target tanggal tayang
- Catatan produksi
- Video yang sudah tayang
- Kalender konten
- Analytics sederhana
- Responsive untuk HP
- Penyimpanan localStorage (gratis)

Catatan:
Versi ini adalah frontend lokal. Untuk dipakai bersama tim dari banyak perangkat, langkah berikutnya adalah menghubungkan database online gratis seperti Supabase.
